# CodeCraft Academy — Хүргэлтийн баталгаажуулалтын checklist

Энэ checklist нь багшийн самбар, сертификат, хэлэлцүүлэг, суралцагчийн сургалтын урсгалын өөрчлөлт бүрийн дараа ашиглана. Автомат суурь шалгалтыг `pnpm run validate` командаар ажиллуулна.

| Шалгах хэсэг | Desktop | Mobile | Хүлээгдэж буй үр дүн |
|---|---:|---:|---|
| `/learn` | 1280×900 | 390×844 | Хичээл → кодын дадал → сорил → хэлэлцүүлэг → сертификатын дараагийн алхам нэг тасралтгүй урсгал болж харагдана. |
| `/admin` | 1280×900 | 390×844 | Багшийн контент засвар, суралцагчийн хайлт/шүүлт, сорилын тайлан, хэлэлцүүлгийн дохио overflow-гүй, уншигдахуйц байна. |
| `/certificate` | 1280×900 | 390×844 | Шалгуур хангаагүй үед тайлбарлагдсан хаалт; хангагдсан үед print/PDF-д зориулагдсан сертификатын зохиомж гарна. |

> Сертификат бэлэн болохын тулд тухайн суралцагч нийтлэгдсэн бүх модулийг дуусгаж, модуль тус бүрийн сорилыг тэнцэх ёстой. Энэ нөхцөлийг `certificateEligibility` unit test батална.

## Автомат баталгаажуулалт

```bash
pnpm run validate
```

Энэ команд нь TypeScript, unit test болон production build-ийг дарааллаар ажиллуулна. Харагдацын шалгалтыг дээрх viewport-оор preview дээр давтан хийнэ.
