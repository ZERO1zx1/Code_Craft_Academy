# CodeCraft Academy — `curriculum.js` хичээлийн бүртгэл

`client/javascript/curriculum.js` нь таван тусдаа сургалтын замтай. Зам бүр **24 хичээлтэй**, нийт **120 хичээл** байна. Бүх lesson нь жишээ код, browser доторх интерактив дасгал, албан эх сурвалжийн холбоос, мөн concept, keyword, prediction, debug, build, review, source awareness зэрэг **10 асуулттай сорил** агуулна.

> Хүндрэлийн шатлал нь course бүрт ижил: 1–8 **Анхан**, 9–17 **Суурь**, 18–24 **Сорилт**.
