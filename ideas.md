# CodeCraft Academy — Visual target

Design direction: **Mongolian-first premium coding lab**. The application should feel like an active practice environment, not a generic course dashboard. Retain a light, approachable learning canvas while using dark navy “lab” surfaces, a confident violet command accent, compact monospace labels, and spacious rounded white work cards. Learner-facing pages should foreground the next real action; staff pages should reuse the lab brand in a data-dense, operational shell.

Signature cues: terminal glyph in the brand mark, subtle grid surfaces on dark lab panels, violet command states, readable Manrope body copy, Space Grotesk display headings, DM Mono micro-labels. Motion is short and purposeful, with clear focus states and reduced-motion support.
