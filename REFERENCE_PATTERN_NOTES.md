# Approved Reference Pattern Notes

## W3Schools — reviewed 2026-08-20

Source: <https://www.w3schools.com>

The page makes four learner routes consistently discoverable for each technology: a tutorial, reference, certification outcome, and a direct “Try it Yourself” editor. Its top navigation also keeps Tutorials, References, Exercises, Certificates, search, and a compact technology rail available without obscuring the first learning action.

### CodeCraft adaptation

CodeCraft will preserve its Mongolian-first curriculum and database-backed progress. The transferable patterns are a clearer course-level action hierarchy, a more explicit bridge between lesson/reference/workspace/quiz, and a compact technology rail for Python, HTML, CSS, and JavaScript. CodeCraft will not copy W3Schools branding, layout, text, or certification claims.

## 1234.mn — reviewed 2026-08-20

Source: <https://1234.mn>

The site foregrounds an all-courses entry point, free-video discovery, search, and a clear course inventory. Course listings expose practical decision data early, including lesson count, duration, viewing signals, and learner count, using Mongolian labels.

### CodeCraft adaptation

CodeCraft will use its own learning-lab visual language and preserve its four connected coding courses. The selected patterns are a direct “all learning paths” route, concise course metadata near each course choice, and Mongolian labels that make course discovery feel familiar. Pricing, basket, and the reference site’s visual identity will not be copied because CodeCraft’s current task is authenticated learning, not commerce.
