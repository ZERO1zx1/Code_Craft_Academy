## Дадлага ба mini-project

Browser-local live preview дээр жишээг өөрчилж semantic profile page-г алхам алхмаар бүтээнэ. Lesson бүрийн төгсгөлд **Эхлэх → Бүтээх → Шалгах** гэсэн 3 шат, deliverable checklist бий.

## Folder доторх файлууд

`index.html` нь 24 lesson-ийн жагсаалт. `01-html-html.html`–`24-html-semantic-audit.html` нь шууд нээгддэг physical lesson page-ууд юм.
