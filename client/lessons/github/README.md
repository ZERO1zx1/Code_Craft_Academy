## Дадлага ба mini-project

Browser-local simulator дээр command sequence төлөвлөж, бодит repository, token, network ашиглахгүйгээр workflow-оо бататгана. Lesson бүрийн төгсгөлд **Эхлэх → Бүтээх → Шалгах** гэсэн 3 шат, deliverable checklist бий.

## Folder доторх файлууд

`index.html` нь 24 lesson-ийн жагсаалт. `01-github-github.html`–`24-github-git-workflow-audit.html` нь шууд нээгддэг physical lesson page-ууд юм.
