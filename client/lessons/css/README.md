## Дадлага ба mini-project

Browser-local preview дээр нэг responsive component-ийг өнгө, зай, layout, media query, transition гэсэн шатлалаар бүтээнэ. Lesson бүрийн төгсгөлд **Эхлэх → Бүтээх → Шалгах** гэсэн 3 шат, deliverable checklist бий.
