## Дадлага ба mini-project

Sandboxed live preview дээр event эсвэл data ашигласан interactive browser widget хийнэ; код server рүү илгээгдэхгүй. Lesson бүрийн төгсгөлд **Эхлэх → Бүтээх → Шалгах** гэсэн 3 шат, deliverable checklist бий.
