# CodeCraft Academy — Хөтөлбөрийн судалгааны тэмдэглэл

## Судалсан эх сурвалж

| Эх сурвалж | Хэрэгжүүлэхэд авах санаа |
|---|---|
| [MDN Curriculum](https://developer.mozilla.org/en-US/curriculum/) | Web standards → semantic HTML → CSS fundamentals → text styling → layout → JavaScript fundamentals гэсэн уялдаа; accessibility, design, version control гэсэн нэмэлт суурь сэдвүүд. |
| [MDN Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn_web_development) | HTML content structure, CSS styling/layout, JavaScript scripting гэсэн тусдаа албан модульд хуваагдсан эхлэгчийн хөтөлбөр. |
| [Python Tutorial](https://docs.python.org/3/tutorial/) | Python-ийн interpreter, control flow, data structures, modules, input/output, errors/exceptions, classes, virtual environments гэсэн суурь шатлал. |
| [Boot.dev curriculum roadmap](https://github.com/bootdotdev/curriculum) | Learning path нь цуврал course-оос тогтох, замаар ахих бүтэц. Хичээл бүрийг уншихаас гадна код бичих дадал, challenge, бодит жижиг төсөлтэй холбох логик. |

## CodeCraft Academy-д хэрэгжүүлэх бүтэц

1. **Хэл бүр тусдаа path** байна: HTML, CSS, JavaScript, Python нь нэг `index.html` жишээнд холилдохгүй. Path бүр нь beginner → core → practice → checkpoint → mini project дарааллаар явна.
2. **Хичээл бүр** ойлголт, tag/keyword/property лавлагаа, ажиллах кодын жишээ, шууд туршилт, автомат шалгалт, hint, тайлбар, дараагийн challenge гэсэн тогтмол бүтэцтэй байна.
3. **Тоглоомжуулалт** нь XP, level, streak бус харин бодит сургалтын үйлдлээс ургана: challenge зөв дуусгах, сорил тэнцэх, даалгавар үнэлгээ авах, дараагийн node нээх.
4. **Тайлбарын хамрах хүрээ** нь зохистойгоор шатална: HTML-ийн semantic/text/media/link/form/table; CSS-ийн selector/cascade/box model/layout/responsive/animation; JavaScript-ийн syntax/data/control flow/function/DOM/async/modules; Python-ийн syntax/collections/control flow/functions/modules/files/exceptions.
