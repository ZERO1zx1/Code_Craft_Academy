# CodeCraft Academy — Дизайны чиглэл

## Зорилго

CodeCraft Academy нь **Mongolian-first premium coding lab** мэдрэмжтэй байна. Суралцагчийн тал нь ойлгомжтой, зорилгод чиглэсэн бөгөөд код бичих бодит орчны итгэлийг төрүүлнэ. Багш, шалгагч, эзэмшигчийн тал нь ижил брэндийн дүрмийг дагасан, харин мэдээлэл нягт ажлын горимоор ажиллана.

## Судалгаанаас авсан зарчим

| Эх сурвалж | Баталгаажсан зарчим | CodeCraft дахь хэрэгжилт |
|---|---|---|
| Duolingo Method | Интерактив “learn by doing”, хувь хүнд тохирсон чиглүүлэг, жижиг ахицын урамшуулал нь суралцагчийг идэвхтэй байлгах үндэс юм.[1] | Дараагийн хичээл, editor CTA, AI чиглүүлэг, badge болон checklist-ийг нэг ахицын хэлхээ болгож харуулна. |
| Khan Academy Wonder Blocks | Боловсролын UI нь empowering, credible, flexible, joyful байх ёстой; дизайн систем нь олон төрлийн хэрэглэгчийг тогтвортой холбодог.[2] | Суралцагчийн үйлдлийг голд тавьсан hierarchy, accessibile token, staff ширээт дэлгэцийн нягт боловч эмх цэгцтэй layout хэрэглэнэ. |
| GitHub Primer | Хуваалцсан accessibility, icon, color, spacing, typography primitives нь бүтээгдэхүүний UI-г нэг систем болгодог.[3] | Violet command accent, navy lab surface, semantic status өнгө, нэг spacing/rounded/shadow системийг бүх дэлгэцэд хэрэглэнэ. |

## Сонгосон visual system

| Хэсэг | Шийдвэр |
|---|---|
| Брэндийн зан чанар | Практик coding mentor: товч, урам өгсөн, хийх үйлдэл тодорхой. |
| Өнгө | **Navy** нь кодын лаборатори; **violet** нь command, идэвхтэй төлөв, ахиц; бусад өнгө нь зөвхөн курс ангилал эсвэл semantic status-д хэрэглэгдэнэ. |
| Typography | Том, итгэлтэй display headline; Monospace micro-label болон code token; body хэсэгт уншихад эвтэй Sans. |
| Гадаргуу | Суралцагчийн journey-д цэвэр цагаан canvas ба dark “lab” hero; workspace-д dark editor; staff интерфэйст ижил accent боловч өгөгдлийн уншигдах чадварыг нэн тэргүүнд тавина. |
| Motion | 160–240ms hover/press/fade transition; `prefers-reduced-motion`-ийг дагана; хөдөлгөөн нь зөвхөн focus ба амжилтын feedback-д ашиглагдана. |
| Accessibility | Өндөр contrast, keyboard focus ring, ойлгомжтой label, semantic өнгө нь зөвхөн өнгөөр утга илэрхийлэхгүй. |

## Хамрах хүрээ

Эхний дизайны шинэчлэл нь shared navigation, global token, learner home, curriculum, workspace, profile, teacher dashboard болон owner operations-ыг хамарна. Бүх одоогийн authentication, permission, progress, invitation, audit, badge, notification урсгал хэвээр үлдэнэ.
