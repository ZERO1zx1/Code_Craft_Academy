# CodeCraft Academy — Нарийвчилсан хөтөлбөрийн судалгааны тэмдэглэл

## Судалгааны зарчим

CodeCraft Academy-ийн lesson нэгж бүр нь нэг тодорхой, шалгаж болох ойлголтод төвлөрнө. HTML-д нэг element/attribute, CSS-д нэг selector/property/concept, JavaScript ба Python-д нэг keyword эсвэл behavior-г тусдаа lesson болгоно. Хөтөлбөрийн тайлбар нь албан ёсны reference рүү шууд холбогдож, суралцагчийн өөрийн кодыг structure, rule эсвэл behavior assertion-оор шалгана.

| Хэл | Албан эх сурвалж | Lesson unit-ийн жишиг |
|---|---|---|
| HTML | [MDN HTML Reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference) | `<h1>`, `<a href>`, `<img alt>`, `<form>`, `required`, `aria-label` |
| CSS | [MDN CSS Reference](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference) | class selector, `margin`, `padding`, `display:flex`, `grid-template-columns`, `@media` |
| JavaScript | [MDN JavaScript Reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference) | `const`, `if`, `function`, `map`, `addEventListener`, `async/await` |
| Python | [Python Tutorial](https://docs.python.org/3/tutorial/index.html) | `print`, `list`, `if`, `for`, `def`, `with`, `try/except`, `class` |

## HTML ба CSS-ийн баталгаажсан зохион байгуулалт

MDN-ийн HTML reference нь element, attribute, global attribute, content category гэсэн бүлгүүдээр HTML-ийн хэсгүүдийг ангилдаг. Иймээс CodeCraft Academy-ийн HTML path нь document/metadata, text semantics, sectioning, linking/media, list/table, form/input, global/accessibility attribute гэсэн дараалалтайгаар нэг tag эсвэл attribute-нэг lesson зарчмыг хэрэгжүүлнэ.[1]

MDN-ийн CSS reference нь property, selector, pseudo-class, pseudo-element, data type, functional notation, at-rule гэсэн ангилалтай. CSS lesson бүр нэг selector/property-г тайлбарлаж, browser CSSOM-оор parse хийгдэх rule/property assertion-тай challenge-аар баталгаажна.[2]

## Хэрэгжүүлэх сургалтын логик

Хичээлийн урсгал нь **тайлбар → богино жишээ → нэг төрлийн асуулт → code/build/debug quest → behavior validation → XP/дараагийн lesson** байна. Нэг сонголттой асуултаас гадна output таах, алдаа олох, code дараалалд оруулах, бүтэц бүтээх, хугацаатай quest, багшийн feedback авдаг submission гэсэн өөр төрлийн сорилуудыг хослуулна.

## JavaScript ба Python-ийн баталгаажсан зохион байгуулалт

MDN-ийн JavaScript reference нь built-in object, statement/declaration, expression/operator, function, class гэсэн үндсэн ангилалтай. CodeCraft Academy-ийн JavaScript path нь `const`, `let`, template literal, comparison, `if`, loop, `function`, `return`, array method, object, destructuring, DOM selector, event listener, `async`, `await`, `try/catch`, module гэсэн тусдаа lesson-уудаар эхэлж, дараа нь behavior quest рүү шилжинэ.[3]

Python-ийн албан tutorial нь calculator/value, text/list, `if`, `for`, `range`, `break`, `continue`, `pass`, function, list comprehension, tuple/set/dict, module, file I/O, exception, class гэсэн нарийвчилсан дараалалтай. Иймээс Python path нь `print`, variable, `str`, `int`, `bool`, list/dict, condition, loop, function, `return`, import, `with open`, `try/except`, `class` зэрэг нэг keyword-нэг lesson structure ашиглана.[4]
