# Figma-inspired learning UI/UX notes

Figma Community-ийн e-learning template collection нь course dashboard, lesson page, quiz зэрэг агуулгыг зохион байгуулалттай, ойлгомжтой navigation-тэй байлгахыг онцолдог. Figma-ийн beginner course нь **auto layout**, дахин ашиглах **component**, туршиж үзэх **prototype**-оор суралцагчийг өөрийн санаагаа бодит page болгон хөгжүүлэх урсгалыг ашигладаг.

CodeCraft Academy-д үүнийг дараах байдлаар хэрэгжүүлнэ. Lesson бүрийн төгсгөлд component-based mini-project card байрлаж, суралцагч нь **Эхлэх → Бүтээх → Шалгах** гэсэн гурван шаттайгаар тухайн keyword-оо ашигласан жижиг үр дүн гаргана. Card нь course accent өнгө, богино deliverable checklist, browser-local action болон feedback-тэй байна; энэ нь backend, account, progress gate үүсгэхгүй.
