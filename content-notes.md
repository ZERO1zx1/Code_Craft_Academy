# CodeCraft Academy — Хөтөлбөрийн агуулгын тэмдэглэл

| Чиглэл | Хичээлийн үндсэн дараалал | Контентын эх сурвалж |
|---|---|---|
| HTML | Синтакс, семантик бүтэц, текст, холбоос, зураг, маягт | MDN Learn: Structuring content with HTML |
| CSS | Сонгогч, cascade, box model, хэмжээс, background/border, responsive layout | MDN Learn: CSS styling basics |
| JavaScript | Хувьсагч ба төрөл, нөхцөл, давталт, функц, өгөгдөл, DOM-ийн суурь | MDN JavaScript Guide |
| Python | Тоо ба текст, list, урсгалын удирдлага, функц, dictionary, модуль, файл | Python Tutorial |

HTML нь вэбийн агуулга, бүтцийг тодорхойлж, семантик тэмдэглэгээ нь хүртээмж, хайлтын систем болон браузерийн суурь чадварт чухал нөлөөтэй. CSS-ийн үндэс нь style, layout, selectors болон box model-оор дамжин тайлбарлагдана. JavaScript-ийн албан гарын авлага нь grammar, data type, control flow, loops, functions гэсэн дарааллаар хэлний суурийг ангилдаг. Python-ийн албан tutorial нь програмчлалын суурь туршлагатай, хэлэнд шинээр орж буй суралцагчдад зориулсан тул энэ эхний замд тоо, текст, list, control flow, function, dictionary сэдвийг хялбарчилж оруулав.

## Эх сурвалж

1. [MDN — Structuring content with HTML](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content)
2. [MDN — CSS styling basics](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics)
3. [MDN — JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide)
4. [Python Software Foundation — The Python Tutorial](https://docs.python.org/3/tutorial/index.html)
