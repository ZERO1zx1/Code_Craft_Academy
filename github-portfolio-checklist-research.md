# CodeCraft Academy — GitHub Portfolio Checklist Research

## Evidence-based checklist scope

Энэ checklist нь суралцагчийн browser-д л хадгалагдах өөрийн бэлтгэлийн жагсаалт юм. GitHub account, API token, repository access шаардахгүй. Item бүр нь суралцагчийг бодит GitHub profile болон repository дээр хийх алхам руу чиглүүлнэ.

| Checklist item | Reason and source |
|---|---|
| Username-тэй ижил нэртэй public profile repository үүсгэх | GitHub profile README харагдахын тулд repository нь username-тэй ижил нэртэй, public, root `README.md`-тэй бөгөөд хоосон биш байх шаардлагатай. [1] |
| Profile README-г зорилго, суралцаж буй технологи, шилдэг project-оор дүүргэх | Profile README нь өөрийгөө profile дээрээ танилцуулах зориулалттай. [1] |
| Showcase repository бүрт тодорхой README нэмэх | README нь project юу хийдэг, яагаад хэрэгтэй, хэрхэн эхлэх, хаанаас тусламж авах, хэн maintain хийдгийг тайлбарлахад ашиглагдана. [3] |
| Шилдэг repository болон gist-ээ pin хийх | GitHub profile дээр repository болон gist-ийг pin хийж, хамгийн сайн ажлаа хурдан олдохоор харуулж болно; нийтдээ зургаа хүртэл item сонгох боломжтой. [2] |
| Feature branch, small commit, pull request review workflow ашиглах | GitHub flow нь branch дээр тусад нь ажиллаж, тодорхой commit, pull request, review, merge урсгалаар change удирдахыг тайлбарладаг. [4] |

## Product behavior

Checklist нь 8 жижиг item, completion count, progress bar, reset action-той байна. Өөр browser эсвэл browser data clear хийхэд checklist дахин хоосорно. Энэ нь үнэгүй, frontend-only хувилбарын privacy зарчимтай нийцнэ.
